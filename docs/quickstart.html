Quickstart & Deployment Guide

Get Kitten-TTS 2 Studio running locally in under 60 seconds with automated virtual environment provisioning, or deploy it as a headless daemon on remote Linux servers and Docker containers.

1. Prerequisites & System Envelope

Kitten-TTS 2 Studio is engineered for strict hardware efficiency. Before bootstrapping, verify that your host environment meets the baseline envelope:

Requirement Minimum Specification Recommended Environment
Operating System Linux (Arch / Ubuntu / Debian / Fedora), macOS (Apple Silicon / Intel), or Windows via WSL2 Omarchy Linux / Arch Linux (Wayland / Hyprland)
Python Runtime Python 3.11+ Python 3.12 (CPython with AVX2 support)
System RAM 8.0 GB Physical RAM (~1.4 GB peak RSS) 16.0 GB Unified / Physical RAM
Audio System FFmpeg installed in $PATH FFmpeg 6.0+ with libopus and pcm encoders
Hardware Acceleration CPU AVX2 SIMD (Standard on all modern x86) NVIDIA GPU with CUDA 12+ (or Apple Silicon M-Series)
💡 FFmpeg Verification Tip

Verify FFmpeg is available on your machine by running ffmpeg -version. On Arch Linux, install via sudo pacman -S ffmpeg; on Ubuntu/Debian, use sudo apt install ffmpeg; on macOS, use brew install ffmpeg.

2. Automated Local Launch (Recommended)

The fastest way to launch Kitten-TTS 2 Studio is using the turnkey launch script run_studio.sh. It automatically creates a localized virtual environment, installs dependencies, verifies audio toolchains, checks hardware acceleration, and boots the workstation:

TERMINAL // ONE-LINE LAUNCH
# 1. Clone the repository
git clone https://github.com/SahooShuvranshu/KittenTTS-Studio.git
cd KittenTTS-Studio

# 2. Run the turnkey boot script
./run_studio.sh

Once booted, the terminal prints hardware telemetry and opens your default browser at http://127.0.0.1:8765/studio.

ℹ️ What run_studio.sh Does Behind the Scenes

1. Verifies Python 3.11+ and checks for ffmpeg.
2. Automatically provisions .venv using uv (if available) or standard python3 -m venv.
3. Installs package dependencies declared in pyproject.toml.
4. Inspects host RAM and probes for CUDA GPU availability.
5. Starts the high-concurrency Uvicorn ASGI server with zero cloud dependencies.

3. Manual Installation with Astral uv / pip

For developers integrating Kitten-TTS 2 Studio into existing toolchains or using high-speed package managers like Astral uv:

BASH // MANUAL UV ENVIRONMENT SETUP
# Create virtual environment
uv venv .venv --python 3.12
source .venv/bin/activate

# Install project in editable development mode
uv pip install -e .

# Run the automated verification suite
python scripts/verify_setup.py

The verification script executes 4 rigorous pre-flight checks:

  • Audio Ingestion: Tests 24kHz mono PCM16 normalization and duration boundary validators.
  • Voice Profiles Vault: Verifies profile CRUD operations in storage/profiles/.
  • Hardware Telemetry: Probes system RAM envelope and detects CUDA/CPU devices.
  • FastAPI App: Validates route bindings for /, /studio, and /api/*.

4. Environment Variables & Binding Options

Customize the server bind address, port, and security headers using standard shell environment variables:

Variable Default Value Description
HOST 127.0.0.1 Network interface to bind. Set to 0.0.0.0 for LAN or cloud access.
PORT 8765 HTTP port for FastAPI and the studio console.
CORS_ORIGINS * Comma-separated list of permitted CORS origins for remote frontend clients.
KITTEN_DEVICE auto-detected Force execution on cpu or cuda.
BASH // CUSTOM PORT & REMOTE BINDING
# Bind to all network interfaces on port 9000 with custom CORS
HOST="0.0.0.0" PORT="9000" CORS_ORIGINS="https://my-app.internal" ./run_studio.sh

5. Headless Daemon & Systemd Service

For permanent 24/7 deployment on dedicated Linux boxes or home servers, create a systemd service unit:

SYSTEMD // /etc/systemd/system/kittentts.service
[Unit]
Description=Kitten-TTS 2 Studio Speech Synthesizer
After=network.target

[Service]
Type=simple
User=shuvransu
WorkingDirectory=/home/shuvransu/Projects/KittenTTS-Studio
Environment="HOST=0.0.0.0" "PORT=8765"
ExecStart=/home/shuvransu/Projects/KittenTTS-Studio/.venv/bin/uvicorn backend.app:app --host 0.0.0.0 --port 8765
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=multi-user.target
BASH // SERVICE ACTIVATION
sudo systemctl daemon-reload
sudo systemctl enable --now kittentts.service
sudo systemctl status kittentts.service

6. Docker Containerization

Run isolated containerized speech instances with optional NVIDIA GPU acceleration:

DOCKERFILE // MULTI-STAGE PYTHON 3.12 BUILD
FROM python:3.12-slim-bookworm
RUN apt-get update && apt-get install -y --no-install-recommends ffmpeg && rm -rf /var/lib/apt/lists/*
WORKDIR /app
COPY pyproject.toml .
RUN pip install --no-cache-dir .
COPY . .
EXPOSE 8765
CMD ["uvicorn", "backend.app:app", "--host", "0.0.0.0", "--port", "8765"]
BASH // DOCKER RUN COMMANDS
# CPU execution mode
docker build -t kittentts-studio .
docker run -d -p 8765:8765 -v $(pwd)/storage:/app/storage kittentts-studio

# NVIDIA GPU mode (with nvidia-container-toolkit)
docker run -d --gpus all -p 8765:8765 -v $(pwd)/storage:/app/storage kittentts-studio
