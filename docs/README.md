# GitHub Pages Documentation

This directory (`docs/`) contains the static documentation website for **Kitten-TTS 2 Studio** by **SahooShuvranshu**.

---

## 🌐 Live URL
When enabled on GitHub, this site is served at:
**`https://sahooshuvranshu.github.io/KittenTTS-Studio`**

---

## ⚙️ Enabling GitHub Pages

1. Navigate to your repository settings on GitHub:
   `https://github.com/SahooShuvranshu/KittenTTS-Studio/settings/pages`
2. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main`.
   - **Folder**: Select `/docs`.
3. Click **Save**.
4. GitHub Pages will build and deploy the documentation website automatically in ~1 minute.
