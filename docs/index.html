⚡ 1.6-bit Ternary SLM Arithmetic Matrix

How does Kitten-TTS 2 execute a 1.7B parameter model on a consumer CPU? By replacing floating-point multiplication with pure integer sign addition and subtraction across ternary weights W ∈ {-1, 0, +1}.

INTERACTIVE ARITHMETIC DEMO // BITNET B1.58 SIGN-FLIP COMPUTE ● CLICK CELLS TO CYCLE {-1, 0, +1}
W = +1 (ADD)
W × X = +X
Direct accumulation, zero multiply cycles needed.
W = 0 (ZERO)
W × X = 0
Complete computation skip, memory bandwidth saved.
W = -1 (SUBTRACT)
W × X = -X
Integer sign-flip subtraction on AVX2 vector register.
CLICK ANY TERNARY WEIGHT TO CYCLE VALUE AND OBSERVE LIVE ACCUMULATION:
W₀ +1 X₀ = 12
W₁ 0 X₁ = 8
W₂ -1 X₂ = 15
W₃ +1 X₃ = 7
W₄ +1 X₄ = 4
FORMULA: (+1 × 12) + (0 × 8) + (-1 × 15) + (+1 × 7) + (+1 × 4)
ACCUMULATOR: +8
5-WEIGHT BYTE PACKING // 3⁵ = 243 ≤ 256 (1.58 BITS / PARAMETER)
ENCODED BYTE VALUE: 0xB7 (183) All 5 ternary weights packed into a single 8-bit byte. Memory compression ratio: ~10x vs FP16.

POST /api/synthesize JSON: { text, speed, profile_id } Synthesize speech with live hardware routing and stopwatch telemetry. { audio_url, duration, latency, device }
POST /api/upload-sample Multipart: file Transcodes arbitrary audio uploads to 24kHz mono 16-bit PCM WAV. { filename, duration, sample_rate, validation }

DELETE /api/profiles/{id} None Deletes voice profile metadata and unlinks WAV asset from disk. { status: "deleted", id }

⚡ Developer Command Center & Quickstart

Spin up the complete Kitten-TTS 2 Studio locally in under 60 seconds across your preferred environment: 

# 1. Clone repository from GitHub
git clone https://github.com/SahooShuvranshu/KittenTTS-Studio.git
cd KittenTTS-Studio

# 2. Ultra-fast virtual environment setup with uv
uv venv --python 3.12
source .venv/bin/activate
uv pip install -r pyproject.toml

# 3. Boot Studio Workstation GUI & REST Server
./run_studio.sh
# Workstation console opens at http://127.0.0.1:8765/studio
# Programmatic Speech Synthesis via Python SDK
from backend.engine import KittenTTSEngine

# 1. Initialize Singleton Engine (loads 1.6-bit Ternary weights)
engine = KittenTTSEngine.get_instance()

# 2. Synthesize with zero-shot voice cloning
filename, duration = engine.synthesize(
    text="[happy] System online. Zero-shot neural voice active.",
    reference_path="storage/profiles/sample_speaker.wav",
    speed=1.0
)

print(f"Generated 24kHz audio: {filename} ({duration:.2f}s)")
# 1. Synthesize speech via REST API
curl -X POST http://127.0.0.1:8765/api/synthesize \
  -H "Content-Type: application/json" \
  -d '{"text": "[happy] System operational. Zero-shot voice active.", "speed": 1.0}'

# 2. Upload reference sample for voice cloning
curl -X POST http://127.0.0.1:8765/api/upload-sample \
  -F "file=@speaker_sample.wav"

# 3. Retrieve system hardware telemetry
curl -s http://127.0.0.1:8765/api/telemetry | jq .
# Deploy on Remote Headless Cloud VPS (Ubuntu / Arch / Debian)
git clone https://github.com/SahooShuvranshu/KittenTTS-Studio.git
cd KittenTTS-Studio

# Bind to public IP on custom port with automatic dependencies
HOST="0.0.0.0" PORT="8765" ./run_studio.sh

# Access remote workstation via browser:
# http://<YOUR_VPS_IP>:8765/studio
# Build and run in isolated Docker container
git clone https://github.com/SahooShuvranshu/KittenTTS-Studio.git
cd KittenTTS-Studio

# Build container image with CUDA & AVX2 support
docker build -t kittentts-studio .

# Run container mapping port 8765
docker run -d -p 8765:8765 --gpus all --name kitten-studio kittentts-studio
