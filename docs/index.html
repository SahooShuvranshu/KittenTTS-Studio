24 kHz Mono Pipeline

[SYS_03] Fallback Engine
Dynamic Hardware Routing
Routes to CUDA when GPU memory allows, and falls back seamlessly to CPU AVX2 on 2GB VRAM constraints with zero crash.
[SYS_04] Persistence
Dual-Engine Audio Writer
Primary C libsndfile writer backed by an automatic pure Python scipy.io.wavfile fallback for 100% resilient audio delivery.

⚙️ Multi-Device Hardware Capability & Portability Matrix

Designed to guarantee zero-configuration execution whether running on high-end servers, battery-constrained laptops, Apple Silicon, or headless cloud containers.

Target Tier Hardware Architecture Inference Execution Synthesis RTF Operational Strategy
Tier 1 Dedicated NVIDIA GPUs (VRAM ≥ 4 GB) CUDA FP16 / BF16 ~0.08x – 0.15x RTF Full GPU flow matching; ultra-fast sub-second turnaround.
Tier 2 Mobile / Shared GPUs (e.g. NVIDIA MX250 2GB) Dynamic CUDA → CPU Fallback ~0.30x – 0.65x RTF Attempts CUDA; catches OOM cleanly and routes to CPU AVX2 instantly.
Tier 3 Apple Silicon (Mac M1 / M2 / M3 / M4) ARM NEON Vectorized ~0.25x – 0.45x RTF Unified memory execution via PyTorch multi-threaded CPU backend.
Tier 4 Headless Cloud / Linux & Windows PCs CPU AVX2 / AVX-512 ~0.40x – 0.85x RTF Standard x86_64 vectorized kernels within 8 GB RAM envelope.

📡 REST API Endpoints & Curl Explorer

The built-in FastAPI server exposes high-performance asynchronous REST endpoints for headless integration and automated speech pipelines:

Method & Path Payload Type Description Response
POST /api/synthesize JSON: { text, speed, profile_id } Synthesize speech with live hardware routing and stopwatch telemetry. { audio_url, duration, latency, device }
POST /api/upload-sample Multipart: file Transcodes arbitrary audio uploads to 24kHz mono 16-bit PCM WAV. { filename, duration, sample_rate, validation }
POST /api/profiles/save-sample JSON: { filename, name, description } Registers and permanently persists voice identity in profile vault. { id, name, filename, duration }
POST /api/profiles/record Multipart: file, name, description Directly registers browser MediaRecorder WebM blob as voice profile. { id, name, filename, duration }
GET /api/profiles None Fetches all registered voice profiles with sample rate & duration. [ { id, name, filename, ... } ]
PUT /api/profiles/{id} JSON: { name, description } Updates voice profile metadata in storage vault. { id, name, description, ... }
DELETE /api/profiles/{id} None Deletes voice profile metadata and unlinks WAV asset from disk. { status: "deleted", id }
GET /api/telemetry None Reports real-time RAM allocation, CPU load, and CUDA GPU status. { ram_used_gb, ram_total_gb, device, gpu_name }
GET /api/audio/{filename} Query: temp, profile Streams generated WAV files with HTTP Range Header seek support. audio/wav Stream
GET /api/history None Retrieves last 50 generated synthesis records with timestamps. [ { id, text, latency, ... } ]
CURL EXPLORER // HEADLESS REST WORKFLOW EXAMPLES
# 1. Synthesize speech via REST API (Default Voice)
curl -X POST http://127.0.0.1:8765/api/synthesize \
  -H "Content-Type: application/json" \
  -d '{"text": "[happy] System operational. Zero-shot neural voice active.", "speed": 1.0}'

# 2. Upload reference sample for voice cloning
curl -X POST http://127.0.0.1:8765/api/upload-sample \
  -F "file=@speaker_sample.wav"

# 3. Retrieve system hardware telemetry & memory utilization
curl -s http://127.0.0.1:8765/api/telemetry | jq .

# 4. Synthesize with cloned voice profile
curl -X POST http://127.0.0.1:8765/api/synthesize \
  -H "Content-Type: application/json" \
  -d '{"text": "[whisper] Secrets encrypted.", "profile_id": "a1b2c3d4"}'
