[SYS_01] Compression
1.6-bit Ternary Weights
Quantized down to ~1.03 GB disk footprint, enabling real-time neural speech synthesis in ~1.2 GB of host RAM without cloud reliance.
[SYS_02] Ingestion
24 kHz Mono Pipeline
Automated FFmpeg transcoding converts incoming MP3, M4A, FLAC, and WebM into clean 16-bit PCM WAV matching model formants.
[SYS_03] Fallback Engine
Dynamic Hardware Routing
Routes to CUDA when GPU memory allows, and falls back seamlessly to CPU AVX2 on 2GB VRAM constraints with zero crash.
[SYS_04] Persistence
Dual-Engine Audio Writer
Primary C libsndfile writer backed by an automatic pure Python scipy.io.wavfile fallback for 100% resilient audio delivery.

⚙️ Multi-Device Hardware Capability & Portability Matrix

Designed to guarantee zero-configuration execution whether running on high-end servers, battery-constrained laptops, Apple Silicon, or headless cloud containers.

Target Tier Hardware Architecture Inference Execution Synthesis RTF Operational Strategy
Tier 1 Dedicated NVIDIA GPUs (VRAM ≥ 4 GB) CUDA FP16 / BF16 ~0.08x – 0.15x RTF Full GPU flow matching; ultra-fast sub-second turnaround.
Tier 2 Mobile / Shared GPUs (e.g. NVIDIA MX250 2GB) Dynamic CUDA → CPU Fallback ~0.30x – 0.65x RTF Attempts CUDA; catches OOM cleanly and routes to CPU AVX2 instantly.
Tier 3 Apple Silicon (Mac M1 / M2 / M3 / M4) ARM NEON Vectorized ~0.25x – 0.45x RTF Unified memory execution via PyTorch multi-threaded CPU backend.
Tier 4 Headless Cloud / Linux & Windows PCs CPU AVX2 / AVX-512 ~0.40x – 0.85x RTF Standard x86_64 vectorized kernels within 8 GB RAM envelope.

📡 REST API Endpoints

The built-in FastAPI server exposes high-performance asynchronous REST endpoints:

Method & Path Payload Type Description Response
POST /api/synthesize JSON: { text, speed, profile_id } Synthesize speech with live hardware selection and stopwatch telemetry. { audio_url, duration, elapsed, device }
POST /api/upload-sample Multipart: file Transcodes arbitrary audio uploads to 24kHz mono 16-bit PCM WAV. { filename, duration, sample_rate }
POST /api/profiles/save-sample JSON: { filename, name } Registers and permanently persists voice identity in profile vault. { id, name, created_at }
GET /api/profiles None Fetches all registered voice profiles with sample rate & duration. [ { id, name, filename, ... } ]
GET /api/telemetry None Reports real-time RAM allocation, CPU load, and CUDA GPU status. { ram_used_gb, ram_total_gb, device, gpu_name }
GET /api/audio/{filename} None Streams generated WAV files with HTTP Range Header seek support. audio/wav Stream
