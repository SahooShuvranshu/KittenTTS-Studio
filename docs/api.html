Asynchronous REST API Reference

Kitten-TTS 2 Studio provides a high-performance REST API powered by FastAPI and Uvicorn. Integrate zero-shot voice cloning, automated speech synthesis, audio normalization, and system telemetry directly into your applications.

1. Base URL & Connectivity

By default, the server listens locally with zero remote network egress:

HTTP // BASE ENDPOINT ADDRESS
http://127.0.0.1:8765
# Content-Type: application/json (or multipart/form-data for file uploads)

2. Complete Endpoint Catalog

Method Endpoint Payload Description Response
POST /api/synthesize JSON (SynthesizeRequest) Main speech synthesis and speaker cloning generator. 200 OK (JSON with audio URL)
POST /api/upload-sample Multipart (file) Normalizes uploaded audio to 24kHz mono PCM WAV. 200 OK (Metadata & validation)
POST /api/profiles/save-sample JSON (filename, name) Promotes temporary sample to permanent voice profile. 200 OK (Profile record)
POST /api/profiles/record Multipart (file, name) Registers browser MediaRecorder WebM microphone clip. 200 OK (Profile record)
GET /api/profiles None Lists all registered voice profiles from storage vault. 200 OK (Array of profiles)
PUT /api/profiles/{id} JSON (name, description) Updates voice profile metadata. 200 OK (Updated profile)
DELETE /api/profiles/{id} None Deletes profile metadata and unlinks WAV from disk. 200 OK (Deleted status)
GET /api/telemetry None Reports live host CPU %, RAM usage, and GPU status. 200 OK (Telemetry object)
GET /api/audio/{filename} Query: temp, profile Streams 24kHz WAV audio with HTTP Range seek support. 200 / 206 (audio/wav)
GET /api/history None Fetches last 50 generated synthesis records. 200 OK (Array of history items)

3. Endpoint Specifications & cURL Examples

POST /api/synthesize

Executes neural speech synthesis. When profile_id or temp_sample is supplied, Kitten-TTS 2 performs zero-shot in-context voice cloning using the reference audio's formant embedding.

Request Schema (application/json)
{
  "text": "[happy] System online and ready for audio production.", // required
  "speed": 1.0,                                                 // optional (0.5 to 2.0, default 1.0)
  "profile_id": "a1b2c3d4",                                     // optional (saved profile ID)
  "temp_sample": null                                           // optional (transient uploaded filename)
}
Response Schema (200 OK)
{
  "id": "gen_1700000000_1a2b3c",
  "filename": "gen_1700000000_1a2b3c.wav",
  "text": "[happy] System online and ready for audio production.",
  "duration": 3.42,
  "latency": 0.48,
  "device": "cpu",
  "profile_used": "a1b2c3d4",
  "audio_url": "/api/audio/gen_1700000000_1a2b3c.wav",
  "created_at": "2026-11-20 08:30:00"
}
CURL // SYNTHESIS REQUEST
curl -X POST http://127.0.0.1:8765/api/synthesize \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello world from Kitten-TTS 2 Studio!", "speed": 1.0}'
POST /api/upload-sample

Ingests any audio file (.wav, .mp3, .m4a, .flac, .ogg), normalizes it to broadcast-standard 24,000 Hz 1-channel mono PCM16 WAV, and evaluates zero-shot duration boundaries.

CURL // AUDIO UPLOAD
curl -X POST http://127.0.0.1:8765/api/upload-sample \
  -F "file=@speaker_sample.wav"
GET /api/telemetry

Polls real-time host RAM, CPU usage, GPU device name, model load status, and active execution mode.

CURL // HOST TELEMETRY
curl -s http://127.0.0.1:8765/api/telemetry | jq .

4. Python Integration Client

A minimal, complete Python script using httpx or requests to perform zero-shot voice cloning programmatically:

PYTHON // CLIENT INTEGRATION (requests) 
import requests

BASE_URL = "http://127.0.0.1:8765"

# Step 1: Upload reference speaker sample
with open("my_speaker.wav", "rb") as f:
    upload_res = requests.post(f"{BASE_URL}/api/upload-sample", files={"file": f}).json()
sample_fn = upload_res["filename"]
print(f"Sample uploaded: {sample_fn} ({upload_res['duration']}s)")

# Step 2: Synthesize speech with cloned voice
synth_payload = {
    "text": "[happy] Zero-shot voice cloning active on consumer hardware!",
    "speed": 1.0,
    "temp_sample": sample_fn
}
synth_res = requests.post(f"{BASE_URL}/api/synthesize", json=synth_payload).json()
print(f"Synthesis finished in {synth_res['latency']}s: {synth_res['audio_url']}")

# Step 3: Download synthesized WAV audio
audio_res = requests.get(f"{BASE_URL}{synth_res['audio_url']}")
with open("cloned_output.wav", "wb") as f:
    f.write(audio_res.content)
print("Saved 24kHz audio to cloned_output.wav")
